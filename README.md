# Simulador-da-M-quina-de-Turing
A partir da linguagem C, foi implementado uma Máquina de Turing que verifica a aceitação de palavras por meio de transições definidas para a máquina. Estruturas encadeadas, alocação dinâmica de memória e recursão foram artifícios utilizados para representar os estados, as transições e explorar os caminhos de execução.
